# 咕嘎指令台（guga-commander）

一句话让桌宠**帮你打开应用**、**打开网站并直接搜**、**把歌收进我喜欢的音乐**、
**打开本机文件**、**打开 Steam 游戏**，或者**自己玩游戏**。

这个插件已经装好了。启动咕嘎（`python launcher.py`）后，在聊天框或语音里直接说中文就行，
不需要再点任何菜单。

> **读文件要先问你**：**第一次**启动咕嘎会弹一张卡片问「允许咕嘎访问本机文件吗」。
> 选**允许访问**才能打开文件；选**以后再说**，插件不读任何文件，项目自带的文件读写也会一起关掉。
> 问过就记住了，之后启动不再打扰——想改就点对话窗口右上角「···」→「软件权限…」。详见第二节。

## 一、能听懂哪些话

| 你说 | 咕嘎做什么 | 实际调用的项目能力 |
| --- | --- | --- |
| `打开微信`、`把记事本打开吧`、`VS Code 开一下` | 拉起 / 复用软件窗口 | `desktop_command` / 原生 `open_app` |
| `有哪些应用` | 列出能打开的软件 | `desktop_command(list)` |
| `打开 D:\报告.pdf`、`把桌面上的合同.docx打开` | 按路径打开文件 | `os.startfile`（需文件权限） |
| `打开我的文档`、`打开桌面`、`打开下载里的安装包.zip` | 打开文件夹 / 按名字找文件 | 本机常用目录检索 |
| `看看桌面上的照片.png` | 打开这个文件 | 同上 |
| `允许读取文件` / `关闭文件权限` | 随时开关文件权限 | 同步「完整访问」开关 |
| `在B站搜索猫`、`用必应查天气`、`淘宝上搜机械键盘`、`在知乎搜一下 PyQt` | 打开那个平台的搜索结果页 | 本地站点表拼 URL（`web_lib`） |
| `打开一个网站`、`打开小破站官网`、`打开 example.com` | 打开对应首页；认不出的名字先搜出来给你点 | `web_lib.open_site` |
| `网易云音乐搜晴天`、`搜一首周杰伦的歌` | 在**网易云客户端**里搜，结果留在客户端窗口 | `cloudmusic_lib`（CEF 窗口键鼠） |
| `用网易云播放晴天`、`网易云里放一下稻香` | 在客户端里搜并播放第一条 | 同上 + 播放条比对 |
| `把晴天加入我喜欢`、`收藏周杰伦的晴天`、`加进我喜欢的音乐` | 在客户端里点第一条结果的 ♥，红了才算成功 | 同上（需完整访问） |
| `打开 steam`、`启动 Steam` | 打开 / 切到 Steam 主窗口 | `steam://open/main` |
| `打开 steam 上的巫师3`、`玩一下大表哥2`、`打开游戏 缺氧`、`打开 cs2` | 按名字匹配本机 Steam 库并启动 | `steam://rungameid/<AppID>` |
| `我 steam 里有什么游戏`、`steam 上有哪些游戏` | 列出库里已安装的游戏 | 本地读 `appmanifest_*.acf` |
| `自己打一局战棋`、`帮我玩炉石 30 步`、`自动对战 5 分钟` | 启动限时自动对战 | `battleground(auto)` |
| `走一步` | 只操作一步，然后报日志回执 | `battleground(step)` |
| `观战` | 只读观察，不发任何游戏输入 | `battleground(observe)` |
| `看看打到哪了` | 查后台状态 | `battleground(status)` |
| `停一下`、`别玩了`、`住手` | 立刻中止 | `battleground(stop)` |
| `自己玩原神` | 如实说明「这个我只能帮你打开」 | 不调用工具 |
| `怎么用` | 打印命令速查 | 不调用工具 |

**游戏名怎么认**：直接读本机 Steam 库里已安装的游戏，支持三种说法——

- 商店原名：`打开 Red Dead Redemption 2`、`打开 need for speed`
- 中文俗称：`大表哥2`、`巫师3`、`cs2`、`无人深空`、`双影奇境`、`壁纸引擎`、`僵毁`、`缺氧`……
- 部分名称：`打开 巫师`、`打开 大镖客`

带数字的会自动区分续作（`巫师3` 不会开成 `巫师2`）。对不上就照实说「Steam 库里没找到」，
并列出你已经装好的游戏；同时对上多个时会让你说全名，不替你猜。

几个例子里带参数：「30 步」改操作上限，「5 分钟」改时间预算。
上限被夹在项目允许的范围里（**1–500 步 / 10–1800 秒**），说「9999 步」也不会越界。

> **安全边界**：只有明确说出「自己玩 / 帮我打 / 自动 / 托管」才会启动自动接管。
> 光说「打开炉石」只会打开游戏，绝不会偷偷开始代打。任何时候说「停一下」都能中止。
> **Steam 游戏只负责启动，不会替你操作游戏**——说「打开大表哥2」只是开游戏，
> 不会去点任何按键。

## 二、本机文件权限（只在第一次启动时问你）

**第一次**启动咕嘎会弹一张卡片（`preview.png` 就是它的样子）：

> 允许咕嘎访问本机文件吗？
>
> 允许后可以直接帮你打开电脑上的文件和软件。

- 点**允许访问** → 打开本机的「完整访问」开关，之后可以说 `打开 D://报告.pdf`、`打开桌面上的合同.docx`；
- 点**以后再说** → 开关保持关闭，插件不读任何文件，项目自带的文件读写、限时命令也一起停用；
- 问过就记住了，**之后启动不再弹窗**；两个按钮都不是默认按钮，手滑按回车不会被授权。

想改的时候：

| 想做什么 | 怎么做 |
| --- | --- |
| 事后允许 | 点对话窗口右上角的「···」→「软件权限…」，勾选「允许咕嘎完整访问本机」；或对我说 `允许读取文件` |
| 事后禁止 | 对我说 `关闭文件权限`，或在同一个面板取消勾选 |
| 再看一眼那张卡片 | `python -m plugins.guga_commander.startup --preview`（只预览外观，不改权限） |
| 看当前状态 | `python plugins/guga_commander/files_lib.py` 打印权限与常用目录 |

**没授权时**说 `打开 D://报告.pdf`，会直接回「本机文件权限没有开启，所以没有读取任何文件」
并给出开启方式，**不会去碰磁盘**。权限判断在 `consent.py`，规则从严：
`file_access.json` 里明确拒绝过，就算别处把开关又打开，也必须重新同意；
`should_ask()` 只认「从没问过且用户没自己动过开关」这一种情况，所以不会反复打扰。

## 三、网站搜索与网易云音乐

这条链路**不经过模型**：说一句「在 B 站搜猫」，插件只是把关键词填进站点模板、
拼出一条网址、交给系统默认浏览器打开。所以模型没配、断网中的大模型报错，都不影响它。

**站内搜索**

| 说法 | 打开的是 |
| --- | --- |
| `在B站搜索猫`、`B站搜原神`、`哔哩哔哩搜一下 教程` | `search.bilibili.com` 的搜索结果 |
| `用必应查天气`、`在百度搜 xxx`、`用谷歌搜 PyQt` | 对应搜索引擎 |
| `淘宝上搜机械键盘`、`京东搜显示器`、`小红书搜露营` | 对应电商 / 社区搜索页 |
| `在知乎搜一下 PyQt`、`微博搜 热搜`、`抖音搜 猫咪` | 对应站内搜索 |
| `在 YouTube 搜 lofi`、`在 GitHub 搜 pyqt5`、`CSDN 搜 PyQt`、`豆瓣电影搜 沙丘` | 各自站内搜索 |
| `网易云音乐搜晴天`、`QQ音乐搜 孤勇者`、`酷狗搜 xxx`、`喜马拉雅搜 xxx` | 对应音乐平台搜索 |

站点表在 `web_lib.py` 的 `SITES` 里，**加一行就能多支持一个站**（见第九节）。认不出站点名时
不会瞎猜网址，会如实说「没认出这个搜索平台」。

**打开网站**

- `打开一个网站` —— 直接开浏览器（必应首页），想搜什么接着说；
- `打开小破站官网`、`打开 B站网站` —— 走站点别名表，开对应首页；
- `打开 example.com` —— 补上 `https://` 直接开；
- `打开一个没听过的网站` —— 认不出就先在必应搜出来，**不会编一个网址糊弄你**。

**网易云音乐（直接操作客户端，不是网页）**

| 说法 | 做什么 |
| --- | --- |
| `网易云音乐搜晴天`、`搜一首周杰伦的歌`、`找首安静点的歌` | 把客户端切到前台，在**它的**搜索框里搜，结果留在客户端窗口 |
| `用网易云播放晴天`、`网易云里放一下稻香`、`用网易云听一下孤勇者` | 搜完直接播第一条，并用播放条有没有变化来确认 |
| `把晴天加入我喜欢`、`收藏周杰伦的晴天`、`把这首歌加进我喜欢的音乐` | 搜完点**搜索结果第一条**那一行的 ♥，再确认它有没有变红 |
| `帮我添加一首音乐进我的喜欢中`（没歌名） | 回一句「要收藏哪一首？」 |
| `把歌加进别的歌单`、`下载这首歌` | 暂不支持，只会加进「我喜欢的音乐」；会如实说明 |

**为什么不能用 UIA**：客户端 3.x 主窗口是 CEF 套壳（窗口类 `OrpheusBrowserHost`），
整棵网页控件树根本没暴露给 UI Automation——宿主去读，只能看到窗口本身一个节点。
所以这条路走的是**真实键鼠**，全部写在 `cloudmusic_lib.py` 里：

1. 找到 `cloudmusic.exe` 的主窗口，还原 + 拉到前台；
2. 点顶部搜索框 → 全选 → 粘贴歌名 → 回车；
3. **悬浮扫描**结果列表：鼠标沿图标列往下走，哪一段亮了就是结果行（连续两次扫到
   同一行才动手——刚加载完的页面会整体跳一下，踩过这个坑）；
4. 点那一行里的 ♥，然后**取色复查**：红心变实心红才算成功。

关于收藏，边界必须讲明：

- ✅ 判定只认一条证据：**那颗 ♥ 从描边变成实心红**（在屏幕上取色，红色像素够多才算）；
- ✅ 「已经喜欢过」也会认出来，不会重复点；
- ⚠️ 需要「完整访问」开启（向别的程序发键鼠属于宿主管控范围），没开会直接告诉你怎么开；
- ⚠️ 窗口必须能到前台（咕嘎会自己切过去）。被其它窗口盖住时取色会读到别人的画面；
- ⚠️ 坐标是客户端 **3.1.x** 的网页排版。换大版本可能整体位移，那时会回
  「没在客户端里认出搜索结果行」，并把窗口停在结果页——**不会盲点一通**；
- ⚠️ 客户端按相关性排序，所以操作对象永远是「搜索结果第一条」，回执也这么写。
  版权受限的歌（比如周杰伦原唱）第一条常常是翻唱；
- 🔁 只有「客户端没装」或「界面认不出来」时才退回网页版（`music_lib.py`，走浏览器
  已登录的账号点 ♥），并在回执里说明这次是在网页版点的。已经点过却没确认到的情况
  **不会**再退一次，避免重复动作；
- ❌ 不碰你的账号密码、不读 cookie、不改歌单之外的任何东西。

## 四、当前项目真实能做什么（请先读这段）

插件只是把项目**已有**的能力用一句话串起来，没有造新的游戏 AI。Steam 部分是插件新增的
「本机库探测 + 系统协议启动」，只负责把游戏拉起来。

**关于 Steam（这次新增）**

- ✅ 读取 Steam 安装位置（注册表 `SteamPath` / `InstallPath` + 常见路径），解析
  `steamapps/libraryfolders.vdf` 和所有库的 `appmanifest_*.acf`，拿到 AppID 与游戏名；
  多个游戏库（C 盘 + D 盘）都能识别，Steam 自带的运行库（Steamworks Common
  Redistributables 等）会被过滤掉。
- ✅ 用 `steam://rungameid/<AppID>` 启动游戏；AppID **只来自本机 manifest**，不接受手输。
- ✅ Steam 没运行时，启动游戏的协议会顺带把 Steam 拉起来。
- ❌ 不代登录、不碰账号密码、不处理 Steam 的更新 / 云同步 / 反作弊弹窗。
- ❌ 不安装、不卸载、不购买游戏；库里没有的游戏只会如实告诉你「没找到」。
- ❌ 不代打 Steam 游戏（唯一能自动操作的是下面说的炉石酒馆战棋）。

**关于酒馆战棋自动操作**

按项目源码和 `docs/battleground-director.md` 的实际边界：

- ✅ 能自动操作的只有**炉石传说 · 酒馆战棋**，而且主要是**招募阶段**的买 / 卖 / 出牌 /
  刷新 / 冻结 / 升本，靠 `Power.log` 日志回执校验每一步。
- ✅ 能打开游戏、切回窗口、只读棋盘、估算胜率、限时多步接管、随时停止、结束后复盘。
- ❌ 不登录战网、不处理更新和认证、不处理发现弹窗 / 目标选择 / 站位、不碰战斗阶段。
- ❌ 不写内存、不调用客户端内部函数，**不承诺无人值守打完整局**。
  项目文档原话：「不能称完整自动代打已经完成」。
- ❌ 其他游戏（原神、LOL、王者荣耀……）**只能帮忙打开**，不会假装能代打。

启动 `auto` 得到的回执是「任务已启动」，不是「已经赢了」。完成后咕嘎会按日志回执报告
实际确认了几步。

## 五、安装 / 查看状态 / 卸载

在项目根目录执行：

```bash
python plugins/guga_commander/install.py              # 安装（重复执行不会重复追加）
python plugins/guga_commander/install.py --status     # 查看安装状态
python plugins/guga_commander/install.py --uninstall  # 卸载并还原
```

安装做了三件事：

1. 在 `core/fast_commands.py` **末尾追加**一段钩子（原有代码一行都不改）。这段钩子在
   运行时把插件规则插到原生 `_match_open_app` **之前**——只有这样「打开大表哥2」这种
   裸游戏名才会先经过 Steam 库匹配，而不是被原生当成软件名报「未找到该软件」。
   插件对非 Steam 目标一律返回 `None`，所以「打开微信」等原有路由完全不受影响；
2. 在 `main.py` 的 `sys.exit(app.exec_())` **之前插入**一段启动弹窗（同样带标记），
   桌宠第一次启动就问一次「能不能读取本机文件」，之后不再打扰。插入后立刻做语法校验，失败就不写。
3. 生成 `plugins/community/guga-commander.json`，让插件出现在咕嘎的「插件市场」里。

安全性：

- 改动前把原文件原样备份成 `core/fast_commands.py.guga-commander.bak`
  与 `main.py.guga-commander.bak`，卸载时**按备份字节级还原**
  （实测 SHA256 与安装前完全一致）；
- 追加后立刻 `compile()` 做语法校验，不通过就中止，原文件不动；
- 全程按字节读写，原文件是 CRLF 还是 LF 都不会被改；
- 钩子整体包在 `try/except` 里——就算把插件目录删了，项目也照常运行，只是少了这些命令。

## 六、不启动桌宠也能验证

```bash
python plugins/guga_commander/commander.py --demo              # 看 30 句话的解析结果
python plugins/guga_commander/commander.py "打开 steam 上的巫师3"  # 看单句解析 / 动作计划
python plugins/guga_commander/steam_lib.py                     # 列出本机 Steam 库和匹配结果
python plugins/guga_commander/files_lib.py                     # 看文件权限状态与常用目录
python plugins/guga_commander/web_lib.py                       # 列出全部站点 + 示例搜索地址
python plugins/guga_commander/music_lib.py "孤勇者"             # 查网易云接口（会联网，只读）
python plugins/guga_commander/cloudmusic_lib.py                # 看客户端在不在、窗口句柄
python plugins/guga_commander/cloudmusic_lib.py "稻香" play     # 真在客户端里搜并播放
python plugins/guga_commander/test_commander.py                # 144 个单元测试
```

`commander.py` / `web_lib.py` / `steam_lib.py` 都是纯标准库，不 import PyQt。
演示模式只打印「这句话会被解析成什么」，**不会真的启动游戏或打开浏览器**；
`web_lib.py` 不加参数时只打表，加 `"在B站搜猫"` 这种参数才会真的开浏览器。

## 七、文件说明

| 文件 | 作用 |
| --- | --- |
| `commander.py` | 核心：中文解析 → 动作计划 → 注入式执行。想加软件别名 / 加命令改这里 |
| `steam_lib.py` | Steam 探测：定位客户端、解析游戏库、中文别名匹配、`steam://` 启动 |
| `app_lib.py` | 本机软件解析：开始菜单快捷方式 + 注册表 App Paths，按中文名启动 |
| `files_lib.py` | 文件解析与打开：认路径、按名字在常用目录里找、`os.startfile` |
| `web_lib.py` | 网站与站内搜索：站点表（40+ 个平台）、搜索 URL 模板、打开浏览器 |
| `cloudmusic_lib.py` | **网易云客户端**：定位窗口、在客户端里搜索/播放/点 ♥，靠真实键鼠 + 取色复查 |
| `music_lib.py` | 网易云网页版（退路）：公开搜索接口取歌、开搜索页、浏览器里点 ♥ 并二次确认 |
| `consent.py` | 文件权限：读写「完整访问」开关，记录问过没有、上次选了什么 |
| `startup.py` | 第一次启动的授权卡片（无边框圆角 + 手绘锁徽标，`--preview` 可只看外观）；`main.py` 里由 `QTimer` 调起 |
| `host_hook.py` | 宿主钩子：`match_rule()` 接住原生没认出的话，`execute()` 执行 |
| `install.py` | 一键安装 / 卸载（幂等、备份、语法校验、字节级还原） |
| `test_commander.py` | 单元测试：解析、计划、执行、网站/音乐/客户端坐标与取色、Steam/文件/权限、安全边界、安装往返 |
| `__init__.py` | 包导出（目录名用下划线是因为 Python 包名不能有连字符） |

生成的分发物：`plugins/community/guga-commander.json`（插件市场卡片）。

## 八、它是怎么工作的

```
桌宠启动
  ↓  main.py 里 QTimer 0.7 秒后弹卡片（只有第一次启动会弹）：允许访问本机文件吗？
  ↓      ├─ 允许访问 → 打开「完整访问」开关（runtime/chat/local_access.json）
  ↓      └─ 以后再说 → 关掉开关，文件能力整项停用
  ↓  选择记进 runtime/guga_commander/file_access.json，之后启动不再问

你说的话
  ↓  core/fast_commands.match()：原生规则依次求值
  ↓  轮到 _match_open_app 之前，插件规则 host_hook.match_rule() 先看一眼
  ↓      ├─ Steam 目标（steam 本体 / 库里的游戏）→ 插件接住
  ↓      ├─ 网站（京东、b站…）                  → 返回 None，原生转 open_url
  ↓      ├─ 站内搜索（在B站搜猫…）              → 插件接住，web_lib 拼地址开浏览器
  ↓      ├─ 网易云搜歌 / 播放 / 收藏           → 插件接住，cloudmusic_lib 在客户端里操作
  ↓      ├─ 已知桌面软件（微信、记事本…）      → 交回原生 open_app
  ↓      ├─ 原生认不出的已装软件（网易云音乐…） → 插件接住，app_lib 直接启动
  ↓      └─ 其它（天气、聊天…）                → 返回 None，原生 / 智能体继续
  ↓  commander.parse()  →  Command(action, target, site, game, appid, 预算)
  ↓
  ├─ open_app          → 交回原生 open_app（后台线程启动，不卡界面）
  ├─ open_local_app    → app_lib.launch()（快捷方式 / exe，本地执行）
  ├─ open_file         → files_lib.open_target()（先验权限，再 os.startfile）
  ├─ site_search       → web_lib.open_search()（站点模板 + 系统默认浏览器）
  ├─ open_site         → web_lib.open_site()（首页 / 域名；认不出就先搜）
  ├─ music_search      → cloudmusic_lib.search()（切前台 → 输歌名 → 回车）
  ├─ music_play        → cloudmusic_lib.play()（搜 → 悬浮扫描找行 → 点播放 → 比对播放条）
  ├─ music_like        → cloudmusic_lib.like()（搜 → 找行 → 点 ♥ → 取色确认变红）
  │                       └─ 只有「客户端没装 / 界面认不出」才退回 music_lib（网页版）
  ├─ open_steam*       → steam_lib（本地执行，不惊动宿主）
  └─ 其他动作           → commander.run() → AppRuntime.execute(工具名, 参数)
                           ├─ desktop_command(open/list/focus)
                           └─ battleground(auto/step/observe/status/stop)
```

四点设计取舍：

1. **只在必要处插队**。插件规则排在原生 `_match_open_app` 之前，但只接自己**真的能做完**
   的句子，其余一律返回 `None`：所以「打开微信」仍走项目原生逻辑（窗口复用、桌面忙时排队
   补开），「打开京东」仍由原生转成 `open_url`，「搜一下天气」仍由原生走百度。
   站内搜索之所以要抢在原生之前，是因为原生只认 30 个站的**首页**，
   「在 B 站搜猫」在它那里没有任何规则能命中，最后只能落到模型上。
2. **不重造轮子**。打开软件走项目已有的 `desktop_command`，玩游戏走已有的
   `BattlegroundDirector`。Steam 游戏没有可以直接点的 exe，才走系统协议，
   而且 AppID 一律从本机 `appmanifest` 读取，不接受手输。
3. **执行器可注入**。`run(cmd, call)` 的 `call(tool, args)` 是参数，测试里传假执行器，
   宿主里传 `AppRuntime.execute`。所以解析层完全不知道 Qt 存在，可以单独跑、单独测。
4. **本地动作不绕宿主**。`steam.*` 三个工具由插件自己完成（`LOCAL_TOOLS`），
   不走 `AppRuntime.execute`——Steam 协议不在 `desktop_command` 的能力范围里，
   也没必要为了启动一个游戏去扫一遍已安装软件。

**两处补丁，都可字节级还原**：`core/fast_commands.py` 末尾追加钩子块；
`main.py` 在 `sys.exit(app.exec_())` 之前插入启动弹窗块。两块都带起止标记，
`install.py --uninstall` 时优先用 `.bak` 原样还原，没有备份才按标记切除。

宿主运行时的获取方式：`find_runtime()` 遍历 Qt 顶层窗口，找到
`ui/agent_chat.py` 里 `self.runtime = AppRuntime(...)` 那个对象。也提供 `bind(runtime)`
供以后显式注册。**没有连上主界面时会明确报错，不会假装成功。**

## 九、自己扩展

**加一个软件别名** → 改 `commander.py` 的 `APP_ALIASES`：

```python
APP_ALIASES = {
    ...
    '代码': 'Visual Studio Code',
    '网易云': '网易云音乐',
}
```

不认识的名字会原样交给项目查已安装软件，所以不加别名通常也能用。

**加一个能搜的网站** → 改 `web_lib.py` 的 `SITES`，一行一个：

```python
SITES = {
    ...
    '少数派': ('少数派', 'https://sspai.com',
               'https://sspai.com/search/post/{q}'),
    '什么值得买': ('什么值得买', 'https://www.smzdm.com',
                   'https://search.smzdm.com/?c=home&s={q}'),
}
```

键是用户可能说的名字（会先转小写、去掉「官网/网站」后缀），值是
`(显示名, 首页, 站内搜索模板)`；`{q}` 会被 URL 编码后的关键词替换。
加完不用改别的代码——`parse()` 的站点正则就是从这张表生成的。

**加一个游戏的叫法** → 改 `steam_lib.py` 的 `GAME_NAME_HINTS`：

```python
GAME_NAME_HINTS = {
    ...
    '大表哥': 'red dead',      # 你的说法 -> 商店名里能找到的英文关键词
    '法环': 'elden ring',
}
```

值是 Steam 商店名里的英文关键词（不区分大小写、忽略标点空格）。只要游戏已经装在
本机，直接说原名或名字的一部分通常就能匹配，不一定要加别名。

**Steam 装在别的盘 / 有多个游戏库** → 不用改代码。插件先读注册表
`SteamPath` / `InstallPath`，再解析 `steamapps/libraryfolders.vdf` 里登记的所有库，
所以 C 盘、D 盘、移动硬盘都行；换库之后重启咕嘎即可（库缓存 30 秒）。

**加一条命令** → 在 `parse()` 里加正则分支，在 `plan_for()` 里加对应的工具调用。
工具名必须是 `core/self_agent.py` 的 `TOOLS` 里已有的（否则宿主不认）。

**想自动玩别的游戏** → 目前做不到：项目只有 `battleground` 一个操作后端，
`AUTO_PLAYABLE` 里只有它。以后项目新增后端，再往 `GAME_ALIASES` / `plan_for()` 里接。
在那之前，插件对别的游戏一律如实回答「只能帮你打开」。

## 十、常见问题

**说「自己打一局」提示「没有连上咕嘎主界面」**
说明只跑了解析层、没启动桌宠。请先 `python launcher.py` 启动咕嘎再说话。

**「打开 XX」提示找不到软件**
项目只会启动它扫描到的已安装软件。可以先说「有哪些应用」看清单，
或者用软件在系统里的准确名称 / 完整 exe 路径。

**说「打开 steam 上的 XX」提示 Steam 库里没找到**
说明这个游戏没装在当前 Steam 账号下——插件只读**已安装**的 `appmanifest`，不查商店、
不查未安装的游戏。说「我 steam 里有什么游戏」看清单，也可以直接说商店原名
（比如 `打开 Red Dead Redemption 2`）。

**说「打开大表哥2」开了别的游戏**
说明库里对上了多个候选，咕嘎会列出候选让你说全名，不会自己挑。说全名即可。

**Steam 启动没反应**
依次看：① Steam 是否已登录；② 游戏是否需要更新（`StateFlags` 不是已就绪）；
③ 游戏是否要求第三方启动器（EA / Ubisoft / Rockstar 等）。
插件只发出启动请求，**不处理更新、登录和第三方启动器**。

**自动对战没反应**
按顺序查：① 炉石和战网是否已登录、能进酒馆战棋；② 说「看看打到哪了」看后台状态；
③ `docs/battleground-director.md` 里列的实机前置条件；④ 部分功能需要以管理员身份
运行 `启动战棋实战.bat`。**插件不负责登录、不绕过权限。**

**启动时没有弹权限窗**
先确认是不是**第一次**启动——权限卡片只弹一次，选过之后就不再打扰，这是设计如此。
想看那张卡片长什么样：`python -m plugins.guga_commander.startup --preview`（只看外观，不改权限）。
如果确实是从没启动过也没弹，说明 `main.py` 的补丁没生效：`python plugins/guga_commander/install.py --status`
看 `startup_prompt` 是不是 `True`；如果是 `False`，说明 `main.py` 结构变了（找不到
插入锚点），重跑一次安装即可。`main.py` 补丁只负责「问」，就算没有它，
插件也会按 `runtime/chat/local_access.json` 里的开关判断权限。

**说「把晴天加入我喜欢」回「没在客户端里认出搜索结果行」**
说明客户端的界面和 3.1.x 的排版对不上了（换了皮肤、改了布局、或者窗口被拖得很窄）。
插件不会盲点，会把客户端停在搜索结果页。这时可以：① 把客户端恢复正常大小再说一次；
② 直接说 `把晴天加入我喜欢` 的重试；③ 自己点一下那颗 ♥。
要确认是不是版本问题：`python plugins/guga_commander/cloudmusic_lib.py` 看能不能找到窗口。

**操作网易云时鼠标自己动了一下**
这是设计如此：客户端是 CEF 套壳，读不到控件树，只能发真实键鼠（点搜索框、粘贴、回车、
点 ♥）。全程大约 3–8 秒，期间请不要抢鼠标。操作完光标会停在那个 ♥ 上。

**「已把搜索结果第一条《X》加进我喜欢」但我想收藏的是原唱**
客户端按相关性排序，第一条不一定是原唱（版权受限的歌常常只有翻唱）。
说的时候带上歌手（`把晴天 周杰伦加入我喜欢`）能显著提高命中率；
歌名越准确，第一条越对。

**说「打开 D://报告.pdf」提示没有文件权限**
说明第一次启动时选了「以后再说」，或者根本没被问过。对我说 `允许读取文件`，
或点对话窗口右上角「···」→「软件权限…」勾上完整访问。

**说「打开桌面上的合同」说没找到**
只在桌面/文档/下载/图片/音乐/视频这几个常用目录里找，深度最多三层、单次最多看 4000 项。
文件放在别处就直接说完整路径（`打开 E://资料//合同.docx`），绝对路径不受这个限制。

**说「在 B 站搜猫」没反应，或者还是报「模型服务域名解析失败」**
搜索这条链路**不经过模型**，理论上不会再报那个错。要是还报，说明桌宠在跑旧代码——
插件是 `import` 进去的，改完必须重启咕嘎（双击根目录的 `重启咕嘎.bat`）。
另外：说「搜一下天气」这种**不带平台名**的话仍然走项目原生的百度搜索，那是另一条链路。

**说「打开一个网站」直接开了浏览器，没打开我要的站**
`打开一个网站` 本来就没说名字，插件只能先开浏览器。要开具体站点请带名字：
`打开小破站官网`、`打开京东`、`打开 example.com`；名字认不出来时会先在必应搜出来给你点。

**收藏没成功**
按顺序查：① 是否开着「完整访问」（收藏要操作浏览器，宿主硬性要求）；
② 浏览器里是否**已登录**网易云（没登录点 ♥ 只会弹登录框）；
③ 是否点到了翻唱版本（回执里带歌手名，核对一下）。
插件只在观察到按钮变成「取消喜欢」才报成功，其余情况会明说「没确认到」，
并把歌曲页留着——点一下那个 ♥ 就行。

**收藏时点错了歌**
歌名是从网易云公开搜索接口取的，按「同名优先、否则第一条」挑，回执里会写清楚
歌名和歌手。想精确一点就带上歌手：`收藏陈奕迅的孤勇者`。

**改坏了想还原**
`python plugins/guga_commander/install.py --uninstall`，会用备份把
`core/fast_commands.py` 和 `main.py` 恢复成安装前的字节。
